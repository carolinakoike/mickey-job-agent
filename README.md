# Mickey Hunter 🐭

Mickey Hunter is a personal job-monitoring agent built with Node.js and TypeScript.

It searches public job sources, filters jobs by keywords, removes already-seen jobs, and sends new matching opportunities to Telegram.

The project was created as a small, incremental personal assistant for monitoring remote and tech job opportunities — especially fixed CLT/PJ jobs, not freelance projects.

## Features

- Search jobs from public sources
- Filter jobs by weighted keywords
- Block unwanted jobs by title or forbidden terms
- Save already-sent jobs locally
- Send Telegram alerts
- Split long Telegram messages automatically
- Support multiple job sources

## Setup

Clone the repository:

```bash
git clone https://github.com/YOUR_USER/mickey-job-agent.git
cd mickey-job-agent
```

Install dependencies:

```bash
npm install
```

Install Playwright Chromium:

```bash
npx playwright install chromium
```

Create your environment file:

```bash
cp .env.example .env
```

Fill in your Telegram credentials:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_telegram_chat_id
```

## How to Create a Telegram Bot

1. Open Telegram.
2. Search for `BotFather`.
3. Send `/newbot`.
4. Choose a bot name.
5. Choose a username ending in `bot`.
6. Copy the generated token.

To get your `TELEGRAM_CHAT_ID`:

1. Send a message to your new bot.
2. Open this URL in your browser:

```txt
https://api.telegram.org/botYOUR_TOKEN/getUpdates
```

3. Copy the `chat.id` value from the response.

## Running Locally

```bash
npm run dev
```

The agent will:

1. Search configured job sources.
2. Filter matching jobs.
3. Remove jobs already sent before.
4. Send new jobs to Telegram.
5. Save sent job URLs in `data/seen-jobs.json`.

## Local Storage

Already-sent jobs are saved in:

```txt
data/seen-jobs.json
```

This prevents the bot from sending the same job repeatedly.

## Current Matching Strategy

The agent uses a simple weighted keyword score.

Examples of positive keywords:

- TypeScript
- JavaScript
- React
- Node.js
- Java
- Spring
- Backend
- Frontend
- Full Stack
- Remote
- Brazil
- LATAM

Some terms are blocked when they appear in the job title, such as:

- Manager
- Director
- Staff
- Principal
- Internship
- Trainee
- Freelance
- Marketing
- Sales
- Designer
- Customer Support

Technologies that are not part of the main target profile should usually reduce the score instead of being fully blocked, because they may appear as optional requirements.
